# Förder-Mathegenerator

Ein responsiver Arbeitsblatt-Baukasten für differenzierte Matheübungen. Die Anwendung nutzt HTML, CSS und JavaScript ohne Frameworks oder Build-Schritt.

## Starten

Öffne `index.html` in einem aktuellen Browser. Es ist keine Installation und kein Server erforderlich.

## Verfügbare Module

- Addition und Subtraktion mit Zahlenraum- und Schwierigkeitsauswahl.
- Multiplikation mit auswählbaren Einmaleins-Reihen.
- Division mit oder ohne Rest.
- Zahlenmauern, Rechendreiecke, Größer/Kleiner/Gleich, Kettenaufgaben, Rechenhäuser und Zahlenstrahl.
- Arbeitsblatt und separates Lösungsblatt als Word-kompatible `.docx`-Dateien.

Das Sachaufgaben-Modul wurde vorübergehend aus der Anwendung entfernt. Die Aufgaben werden lokal im Browser erzeugt; Eingaben werden nicht an einen Server übertragen. PDF-Export ist nicht enthalten.
