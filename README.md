# Förder-Mathegenerator

Ein responsiver Arbeitsblatt-Baukasten für differenzierte Matheübungen. Die Anwendung nutzt bewusst nur HTML, CSS und JavaScript ohne Frameworks oder Build-Schritt.

## Starten

Öffne `index.html` in einem aktuellen Browser. Es ist keine Installation und kein Server erforderlich.

## Erste Version

- Module für Addition, Subtraktion, Multiplikation, Division und Sachaufgaben kombinieren.
- Zahlenräume und Aufgabenschwierigkeiten für Addition und Subtraktion auswählen.
- Einmaleins-Reihen einzeln oder über Schnellfilter auswählen.
- Sachaufgaben nach Thema, Rechenart und Sprachstufe erzeugen.
- Arbeitsblatt und separates Lösungsblatt als Word-kompatible `.docx`-Dateien herunterladen.
- Anpassbares Layout für Desktop, Tablet und Smartphone.

Die Aufgaben werden lokal im Browser erzeugt. Es werden keine Eingaben an einen Server übertragen. PDF-Export sowie das Löschen, Bearbeiten und Verschieben bereits hinzugefügter Module sind nicht Teil dieser ersten Version.
